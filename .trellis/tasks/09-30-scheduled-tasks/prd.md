# 定时任务：银行员工友好的智能体定时执行

## Goal

让不懂技术的银行员工，用"点选"的方式就能让昆小智在固定时间自动完成工作
（例如"每个工作日 8:30 整理今日重点"、"每周五 17:00 生成本周工作周报"），
执行完成后主动通知本人，并能随时回看每次执行的结果。

底层逻辑参考 LambChat 的 `src/infra/scheduler/*`（APScheduler + MongoDB 持久化
+ Redis 分布式锁 + 独立会话执行 + 运行记录），UI 与交互按昆小智自身用户群重新设计。

## Users & Constraints

- 用户是银行一线/中后台员工，不理解 cron、UTC、时区、秒级间隔等概念。
- 部署在银行内网，多副本（K8s）运行，必须保证同一时刻同一任务只执行一次。
- 不得影响聊天主链路；定时执行沿用现有 `BackgroundTaskManager`（local / arq 双后端）。
- 默认时区 `Asia/Shanghai`，所有展示为北京时间。

## Requirements

### R1 友好的频率模型（核心）
- 用户选择以下之一，不接触 cron：
  - 每天 HH:MM；每个工作日（周一至周五）HH:MM；每周指定星期几 HH:MM；
  - 每月 N 号 HH:MM（支持"每月最后一天"）；仅一次（指定日期时间）；
  - 每隔 N 小时（高级，1–24 小时）。
- 后端把友好频率编译成 APScheduler Trigger，并生成中文自然语言描述
  （如"每个工作日 08:30"），前后端描述一致。
- 提供"预览"接口：返回接下来 5 次执行时间与校验错误（中文、可读）。

### R2 任务内容
- 名称、要让昆小智做的事（提示词）、可选使用某个角色（Persona）、可选模型。
- 内置场景模板（晨间简报、工作周报、月度总结、合规提醒、学习打卡等），一键套用后可改。

### R3 执行与可靠性
- 每次触发创建独立隐藏会话执行（不污染侧边栏会话列表），记录运行记录：
  状态（执行中/成功/失败/超时/跳过）、耗时、结果摘要、会话链接、错误信息。
- 多副本去重：Redis 触发槽锁（slot）+ 执行锁（token CAS 释放）。
- 超时取消、失败重试（0–3 次）。
- 连续失败 3 次自动暂停，并通知用户原因（防止坏任务每天刷失败）。
- "仅一次"任务执行后自动结束（状态改为已完成/暂停）。
- 进程重启后从 MongoDB 恢复所有启用任务；其他副本新增/修改的任务在 60 秒内生效。

### R4 通知
- 执行完成（成功或失败）通过现有 WebSocket 推送给任务所有者，前端弹出提示，
  可一键查看结果。

### R5 管控
- 每用户任务数上限（默认 20）、最小间隔（默认 1 小时）、功能总开关，
  均走现有 `SETTING_DEFINITIONS` 体系，管理员可在设置页调整。
- 所有接口按 owner 隔离；需要 `chat:write` 权限。

### R6 前端
- 新增"定时任务"页面（侧边栏入口），列表卡片显示：名称、中文频率描述、
  下次执行时间、最近一次结果、启用开关。
- 创建/编辑向导：① 选模板或空白 → ② 写要做的事 → ③ 选时间（大按钮 + 时间选择）
  → 实时预览"接下来会在这些时间执行"。
- 操作：立即执行一次、暂停/恢复、编辑、删除（二次确认）、查看运行记录并跳转会话。
- 中文/英文文案齐全（其他语言回落英文）。

## Acceptance Criteria

- [ ] 五种友好频率均能正确编译为触发器，预览的下次时间符合北京时间预期（单测）。
- [ ] 最小间隔、任务数上限、过去时间的"仅一次"会被拒绝并给出中文提示（单测）。
- [ ] 同一触发槽在两个 runner 并发时只执行一次（单测，fake redis）。
- [ ] 连续失败达到阈值自动暂停（单测）。
- [ ] 启动时恢复任务、周期同步不重复注册（单测）。
- [ ] API CRUD / pause / resume / run-now / runs / preview 可用且 owner 隔离（单测）。
- [ ] 定时会话不出现在普通会话列表中。
- [ ] 前端 `tsc` 通过；页面可创建、预览、立即执行、查看记录。

## Out of Scope（后续迭代）

- 对话中让智能体直接创建定时任务（Agent tool），企业微信推送结果，
  法定节假日日历（当前"工作日"=周一至周五，UI 已提示）。
